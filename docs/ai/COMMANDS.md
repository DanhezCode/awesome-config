# Commands

## Common commands

Run these from the repository root with Bun:

- `bun run lint` — run oxlint.
- `bun run lint:fix` — auto-fix lint issues.
- `bun run fmt` — check formatting.
- `bun run fmt:fix` — apply formatting fixes.
- `bun run cspell` — run spell checking.
- `bun run test` — run the Vitest suite.
- `bun run test:cov` — run Vitest with coverage.
- `bun run check` — run formatting, linting, and spelling checks together.
- `bun run fix` — run formatting and lint fixes together.

## Notes

- The repository uses Bun as the package manager and runtime.
- Use the commands above instead of ad-hoc shell commands when validating changes.
