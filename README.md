# awesome-config

A curated collection of editor and project configuration files, templates, and recommended defaults for JavaScript/TypeScript projects.

## Installation

This repository contains configuration files (ESLint, Prettier, TypeScript, etc.) that you can copy into your projects.

To install published package from npm (if published):

```bash
npm install -D awesome-config
# or with bun
bun add -D awesome-config
```

## Usage

Copy the files or refer to the specific configuration pieces you need (for example, `.eslintrc`, `prettier.config.js`, or `tsconfig.json`). This repo is intended as a reference and starter kit.
